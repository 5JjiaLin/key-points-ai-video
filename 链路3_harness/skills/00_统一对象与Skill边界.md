# 见知·经纬：统一对象与 Skill 边界 v1

## 1. 最终产品结果

最终结果不是一份多视频摘要，而是：

> 根据用户研究目标生成的、具有明确阶段和知识关系、每个节点能回到原视频片段的个性化学习路径。

---

# 2. 核心对象

## 2.1 VideoSetAssessment

描述当前视频集合是否适合构建同一主题知识档案。

核心字段：

```json
{
  "theme_id": "topic_001",
  "theme_title": "地球形成与早期演化",
  "scope_statement": "围绕地球形成、内部热源、大气演化与早期生命影响",
  "analysis_mode": "multi_creator_topic",
  "included_video_ids": ["v001", "v002"],
  "excluded_video_ids": ["v009"],
  "confidence": 0.92
}
```

---

## 2.2 SourceKnowledgePoint

表示某一条视频实际讲到的最小可学习单元。

它回答：

> 这条视频在这个时间片段讲了什么？

必须保留原始来源和证据，不受用户问题影响。

---

## 2.3 CanonicalKnowledgeNode

表示跨视频标准化后的稳定知识节点。

它回答：

> 多条视频共同构成的主题知识中，客观上有哪些独立知识命题？

一个标准节点可以有多个来源。

---

## 2.4 KnowledgeRelation

表示标准节点之间或来源观点之间的关系。

包括：

- 前置；
- 深化；
- 因果；
- 过程；
- 时间；
- 互补；
- 共识；
- 条件差异；
- 真实分歧。

---

## 2.5 ResearchIntent

表示用户研究问题对应的可执行编排约束。

它不直接生成路径。

---

## 2.6 LearningPath

表示当前用户目标下的学习结果。

它可以随研究问题改变，但不得修改稳定知识底座。

---

# 3. 稳定层与动态层

## 稳定层

```text
S0 视频集合准入与主题识别
S1 来源知识点提取
S2 跨视频知识标准化
S3 知识关系与来源校准
```

同一批视频和同一版本下应缓存复用。

## 动态层

```text
S4 研究问题推荐
S5 研究问题解析
S6 知识筛选与路径编排
S7 学习路径审核
```

用户更换研究问题时重跑。

---

# 4. 分析模式

## single_creator_series

面向同一创作者系列。

重点关系：

```text
章节
前置
后续
深化
重复
补充
缺失
```

## multi_creator_topic

面向多创作者同主题。

重点关系：

```text
重复
互补
共识
独有补充
条件不同
真实分歧
证据不足
```

分析模式影响关系判断和路径策略，但不改变来源知识点内容。

---

# 5. Skill 不负责的工作

以下必须由 Harness 或确定性代码完成：

- JSON Schema 校验；
- ID 生成；
- 时间戳是否合法；
- 来源视频和知识点 ID 是否存在；
- 缓存键计算；
- 片段时长求和；
- 学习时间基础计算；
- 图关系自环和环路检测；
- 拓扑排序；
- 去除重复边；
- 最大重试次数；
- 中间状态保存；
- Trace；
- 前端进度；
- 用户学习进度。

模型擅长语义判断，不必让它顺便兼职数据库和图算法。那对双方都不礼貌。

---

# 6. 统一执行状态

每个 Skill 顶层都应输出：

```json
{
  "status": "passed | partial | failed | needs_review",
  "issues": [
    {
      "code": "string",
      "severity": "low | medium | high",
      "message": "string",
      "affected_ids": ["id"],
      "retry_step": "string|null"
    }
  ]
}
```

---

# 7. 统一来源原则

任何核心结论都必须满足：

```text
学习路径节点
→ 标准知识节点
→ 来源知识点
→ 视频
→ 时间片段
→ 原始证据
```

不得只保存模型生成的摘要而丢失原文。

---

# 8. 统一边界原则

## 不得过度合并

同一主题不等于同一知识。

```text
概念定义
发生原因
形成过程
产生影响
实际应用
```

必须是不同节点。

## 不得制造冲突

表达不同不等于观点冲突。

必须先对齐：

- 对象；
- 命题；
- 时间范围；
- 适用条件；
- 定义口径。

## 不得偷偷补课

现有视频没有覆盖必要前置时：

```text
标记 missing_prerequisite
```

不得生成一个没有来源的新课程节点。

## 不得按视频顺序偷懒

发布时间、收藏顺序、播放顺序和视频编号都不能直接作为学习顺序。
