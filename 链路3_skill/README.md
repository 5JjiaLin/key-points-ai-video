# 见知·经纬：链路3 Skill 包 v1

## 1. 目标

本 Skill 包用于把多条相关视频中的零散知识，重构成一条：

- 符合用户研究目标；
- 有合理分类和学习顺序；
- 能解释前置、因果、互补、时间、共识或分歧关系；
- 每个节点都能回到原视频关键片段；
- 更换研究问题时无需重新解析视频；

的个性化学习路径。

一句话结果：

> 把多条视频中的知识点统一、去重并建立关系，再根据用户目标重构成可学习、可追溯的个性化知识路径。

---

## 2. 第一性原理

链路3不是“多视频摘要”。

它必须先构建与用户问题无关的稳定知识底座，再基于用户目标生成动态学习路径。

```text
稳定知识层
视频集合
→ 来源知识点
→ 标准知识节点
→ 知识关系图

动态路径层
研究问题
→ 筛选
→ 分类
→ 排序
→ 阶段划分
→ 学习路径
→ 独立审核
```

用户更换研究问题时，只重跑动态路径层。

## 3. Skill 列表

| 编号 | Skill | 核心职责 | 层级 |
|---|---|---|---|
| S0 | 视频集合准入与主题识别 | 判断哪些视频属于当前主题，并识别来源结构 | 稳定层 |
| S1 | 来源知识点提取双模式 | 复用链路2解析能力，生成可重构的来源知识点 | 稳定层 |
| S2 | 跨视频知识标准化 | 将同一独立命题的不同表达映射为标准节点 | 稳定层 |
| S3 | 知识关系与来源校准 | 建立前置、因果、互补、共识、条件差异和分歧 | 稳定层 |
| S4 | 研究问题推荐 | 根据当前知识覆盖推荐3至4个可执行研究问题 | 动态入口 |
| S5 | 研究问题解析 | 将自然语言需求转成可执行编排约束 | 动态层 |
| S6 | 知识筛选与路径编排 | 筛选、分组、排序、分阶段并绑定来源 | 动态层 |
| S7 | 学习路径独立审核 | 审核目标、约束、关系、来源、时间与幻觉 | 动态层 |

## 4. 推荐执行顺序

```text
用户选择或系统发现多条相关视频
↓
S0 视频集合准入与主题识别
↓
读取链路2知识点缓存
├─ 已有 reconstruction_base 结果 → 直接复用
└─ 没有 → S1 来源知识点提取
↓
S2 跨视频知识标准化
↓
S3 知识关系与来源校准
↓
形成 TopicKnowledgeProfile
↓
S4 推荐研究问题 或 用户自定义问题
↓
S5 研究问题解析
↓
S6 知识筛选与路径编排
↓
S7 学习路径独立审核
↓
通过 → 发布
失败 → 依据 retry_step 局部重跑
```

## 5. 与链路2的复用关系

链路2现有知识点 Skill 偏向：

> 选择能形成好问题、短答案和回看钩子的知识点。

链路3需要：

> 提取相对完整、稳定、可跨视频统一的最小可学习单元。

因此 S1 采用双模式：

```text
navigation
→ 服务链路2，保留题目张力和答案钩子要求

reconstruction_base
→ 服务链路3，保留完整事实、时间戳和边界要求
→ 取消“必须有强题目张力”的硬门槛
→ 补充定义、前置知识和结构性知识
```

两种模式共享视频解析、语义切段、事实句、时间戳和来源证据，但输出用途不同。

---

## 6. 三种对象必须隔离

```text
SourceKnowledgePoint
某条视频实际讲到的知识

CanonicalKnowledgeNode
跨视频统一后的稳定知识节点

LearningPathNode
某个用户目标下的学习展示节点
```

不得使用同一个 `knowledge_point` 对象同时承担三种职责。

---

## 7. 关键硬规则

1. 视频内容决定来源知识点，用户研究问题不得反向修改它。
2. 标准化只合并同一独立命题，不合并定义、原因、过程、结果等不同维度。
3. 学习路径只能引用已有标准节点，不得擅自补写核心知识。
4. 缺少前置知识时只能标记缺口，第一版不自动调用外部知识补齐。
5. 所有标准节点和路径节点必须保留来源视频、时间点和证据。
6. 单博主模式强调课程逻辑，多博主模式强调来源整合，但不改变基础知识事实。
7. 路径编排与路径审核必须是两次独立调用。
