# 链路3 Skill 回归测试集与验收指标 v1

## 1. 目的

Skill 修改后必须使用固定样本回归，避免某个案例变好，另一个边界却悄悄坏掉。模型的“优化”经常像搬家，客厅整洁了，东西全塞进卧室。

---

# 2. 最小回归场景

## Case 1：同一过程的不同表达

来源：

```text
原行星吸积
早期物质聚集
太阳系尘埃逐渐结合
```

预期：

- 合并为一个标准过程节点；
- 保留三个原始表达；
- 保留全部来源。

---

## Case 2：同一主题的不同维度

来源：

```text
大氧化事件是什么
大氧化事件为什么发生
大氧化事件造成什么影响
```

预期：

- 形成 definition、cause、effect 三个节点；
- 禁止合并成一个“大氧化事件”。

---

## Case 3：英语词汇不同学习任务

来源：

```text
abandon 的含义
abandon 的使用场景
abandon 与 give up 的区别
abandon 在雅思写作中的用法
```

预期：

- 至少四个独立节点；
- “只学习雅思写作”时保留雅思用法；
- 必要词义可作为前置；
- 日常场景可排除或降级。

---

## Case 4：条件不同而非冲突

来源A：

```text
胃肠敏感人群喝冰水可能出现短暂不适
```

来源B：

```text
多数健康人适量喝冰水通常不会造成长期胃损伤
```

预期：

```text
condition_difference
```

不得判 conflict。

---

## Case 5：多因素互补

来源A：

```text
地球内部仍有早期形成留下的残余热
```

来源B：

```text
放射性元素衰变持续释放热量
```

预期：

```text
perspective_complement
```

不得只保留一个因素。

---

## Case 6：单博主视频顺序混乱

输入：

```text
第4集
第1集
补充篇
第3集
第2集
```

预期：

- 不按收藏顺序；
- 根据章节和前置关系恢复；
- 补充篇放在相关主章节后；
- 缺失章节明确标记。

---

## Case 7：用户问题超出视频范围

视频只包含旅游口语。

用户：

```text
只学习雅思写作表达
```

预期：

```text
coverage_assessment = unsupported
```

不生成伪造的雅思路径。

---

## Case 8：缺少前置知识

现有节点包含：

```text
Transformer注意力机制
Agent工具调用
```

缺少：

```text
神经网络基础
大模型基本概念
```

预期：

- 标记 missing_prerequisite；
- 不生成无来源的前置课程节点。

---

## Case 9：研究问题改变但知识底座不变

同一批视频：

```text
问题A：从易到难
问题B：只学生活场景
问题C：7天每天15分钟
```

预期：

- SourceKnowledgePoint 集合不变；
- CanonicalKnowledgeNode 核心集合不变；
- LearningPath 明显不同。

---

## Case 10：链路2与链路3提取模式差异

同一视频包含：

- 一个反差很强的核心知识；
- 一个必要定义；
- 一个无张力但重要的前置；
- 一个广告段落。

预期：

```text
navigation
→ 主要选择反差核心知识

reconstruction_base
→ 保留核心、定义和前置
→ 排除广告
```

# 3. Skill 级指标

## S0 视频集合准入

- 核心视频召回率；
- 无关视频排除准确率；
- 主题范围稳定性；
- 模式推荐准确率。

## S1 来源知识点提取

- 核心知识召回率；
- 原子性准确率；
- 时间段准确率；
- 来源证据完整率；
- reconstruction_base 主干覆盖率。

## S2 标准化

- 正确合并率；
- 过度合并率；
- 漏合并率；
- 来源保留率；
- 标准陈述忠实度。

## S3 关系判断

- 前置关系准确率；
- 因果/时间关系准确率；
- conflict 误判率；
- condition_difference 识别率；
- 来源证据完整率。

## S5 研究问题解析

- 核心字段一致率；
- 硬约束识别率；
- 排除项保留率；
- 覆盖不足识别率。

## S6 路径编排

- 用户目标匹配度；
- 关键节点召回率；
- 明显重复率；
- 前置违规率；
- 来源可追溯率；
- 模板选择准确率。

## S7 路径审核

- 高严重度错误召回率；
- 错误 retry_step 准确率；
- 不合格路径误放行率；
- 合格路径误拒率。

# 4. 稳定性验收

同一输入重复执行5次：

```text
研究意图核心字段一致率 ≥ 90%
来源知识点核心集合重合率 ≥ 85%
标准节点核心集合重合率 ≥ 85%
核心关系重合率 ≥ 80%
路径核心节点重合率 ≥ 80%
核心阶段结构一致率 ≥ 80%
Schema通过率 = 100%
来源可追溯率 = 100%
```

这些是MVP实验阈值，不是自然定律，但总比“这次看起来不错”更接近测试。

# 6. Skill 升级规则

只有满足以下条件才发布新版本：

1. 新增规则有明确失败案例；
2. 固定回归集整体不下降；
3. Schema 未发生未说明的破坏性变化；
4. 版本号与变更记录已更新；
5. 至少抽样审核三个不同知识领域；
6. 不使用单一视频案例证明“已经稳定”。
