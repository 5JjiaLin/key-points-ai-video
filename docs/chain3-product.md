# 链路 3 产品说明：多视频知识重构

## 定义与位置

链路 3 面向“收藏了多条相关视频，但仍缺少可学习结构”的场景。它位于两条单视频链路之后：

1. 链路 1 在播放时补齐理解障碍；
2. 链路 2 提取单条视频的知识点、证据和完整解释区间；
3. 链路 3 复用这些产物，把 3–10 条同主题视频重构为可追溯的学习路径。

链路 3 不重复下载视频，也不重复执行 ASR、OCR 或关键帧提取。

## 两种分析方式

### 单博主系列

对同一创作者的系列视频恢复合理学习顺序，识别前置、后续与系列完整性。创作者的发布顺序是证据之一，但不自动等同于学习顺序。

### 多博主同主题

合并不同创作者对同一主题的重复与互补知识，比较有来源支撑的观点差异，构建更完整的知识路线。系统不为了“有冲突”而制造冲突。

## 稳定知识层与动态路径层

稳定知识层只依赖视频集合，包含：

- 来源知识点与原视频时间范围；
- 跨视频标准知识节点；
- 前置、因果、时间、互补和观点等关系；
- 来源覆盖、重复、差异和知识缺口。

动态路径层依赖用户的研究问题，负责筛选知识、排序、估算学习时间并生成路径。同一稳定知识层可以复用并回答不同研究问题，无需重新解析视频。

## S0–S7 固定流程

| Step | Responsibility |
| --- | --- |
| S0 | 视频集合准入、主题相关性与 3–10 条数量门禁 |
| S1 | 按视频提取或复用来源知识点 |
| S2 | 跨视频知识标准化 |
| S3 | 建立知识关系并校准来源 |
| S4 | 在用户未提供问题时推荐中立研究问题 |
| S5 | 解析用户选定或自定义的研究问题 |
| S6 | 筛选知识并编排学习路径 |
| S7 | 独立审核路径完整性、可追溯性与质量 |

Harness 采用确定性 Orchestrator 驱动固定顺序。模型只完成边界明确的 Skill；Schema、来源、时间范围、图关系、循环、时长、缓存、重试和发布状态由确定性代码控制。

## 产品流程

```text
收藏 / 发现视频
→ 选择单博主系列或多博主同主题
→ 选择或输入研究问题
→ AI 建立稳定知识层并编排路径
→ 查看时间线、观点比较与推荐学习路径
→ 每个节点返回原视频片段
```

## 数据与质量边界

- 只接受 3–10 条已完成解析、具有可复用证据的视频；
- 混合主题或证据不足的视频集合应被拒绝，而不是勉强生成；
- 不使用简单关键词命中代替语义关系；
- 不过度去重，互补解释和有意义差异应保留；
- 不自动补充视频外知识；如未来接入外部知识，必须单独标记来源；
- 每个学习节点必须保留来源视频 ID 和时间范围；
- 只有 `completed` 结果可以发布，`needs_review` 或 `failed` 不得伪装成成功。

## 稳定接口

公开集成通过 Backend API 进行，调用方不直接依赖各链路内部实现。跨链路稳定边界为 `video-environment.v1`、`video-project.v1`、`source-knowledge-artifact.v1` 与 Learning Path Schema。

可运行 Harness、Schema、Fixture 和测试位于 [`链路3_harness`](../链路3_harness)，对外调用 Skill 位于 [`delivery/huazhongdian-video-harness`](../delivery/huazhongdian-video-harness)。

## 当前不负责

- 外部知识自动补全或联网事实核验；
- 大规模知识图数据库与多用户协作；
- 自动考试、账号体系或生产级队列；
- 对模型准确率、学习效果或用户增长作未经验证的承诺。
